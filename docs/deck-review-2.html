03 · THE GATE

Every sprint, the same bar

  • Python: 235/235 · Node: 62/62 · Harness: 60/60 · typecheck + build clean.
  • Every sprint ended with an independent review (backend, frontend, verifier) and a fix pass.
  • The reviews caught real bugs: a resume picker that would have attached someone else's file, a fill path that was a TypeError in production, a cooldown that swallowed real changes.

04 · PRIVACY, PROVEN

What a judge can check

  • What was sent: every outbound payload, redacted, with timestamp, endpoint, token count.
  • Egress audit: live grep of outbound requests — 0 hits, pattern listed.
  • Redaction proof: second scan finds 0 recoverable tokens.
  • Audit log: hash-chained, verifiable. It proves tampering after the fact — it does not prevent it, and we say so.

05 · LIVE DEMO

The job hunt, end to end

  • Find SDE internships → shortlist 5 matching roles → fill the application → approve → receipt.
  • Diff view: redacted payloads with placeholder tokens highlighted, plus the PII types removed — and the honest note that no raw side exists, because raw PII is never stored.
